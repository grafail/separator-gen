# separator-gen
A library to generate fixed size horizontal separators for Jetbrain IDEs.

Because every IDE deserves a nice, well-aligned separator—unlike my code indentation.
Generated separators: 100%. Generated bugs: please don’t check the logs.
If it crashes, it’s not a bug—it’s a surprise feature for your next stand-up.

### Build Command:
```bash
./gradlew buildPlugin
```
